1) Install Linux

2) Set up hosts file (if IPs are outdated, see [DoH.txt](DoH.txt) on how to resolve)

3) Apply [iptables.sh](iptables.sh)

4) Update OS (e.g. `apt update` / `apt upgrade`)

5) Install PKCS#11 lib (optional)

6) Install openjdk-17-jre

7) Create [iptables-service (run on startup).md](iptables-service%20%28run%20on%20startup%29.md)

8) SocksUI: Download from github (https://github.com/flower-org/FlowerNet/releases))

9) Set up programs like Firefox to use SocksUI proxy
